## 🧠 Overview

**HeartHive** is a cutting-edge heart disease prediction application that utilizes a **Transformer model optimized with Particle Swarm Optimization (PSO)**. It incorporates **SHAP Explainable AI** to interpret results and leverages **DeepSeek AI** to provide personalized health recommendations based on key features influencing each prediction.

---

## 🧱 Architecture

```text
User Input → Scaler → PSO-Optimized Transformer Model → Prediction (Yes/No)
                                                 ↓
                                  SHAP Explainer → Top Risk Factors
                                                 ↓
                           DeepSeek AI → Do's and Don’ts (based on SHAP)
                                                 ↓
                                       Streamlit UI Output

```
